Setup ke Steps

  1. supabase.com par free account banayein aur ek naya project banayein.
  2. Project ke andar bayen taraf SQL Editor par jayein, aur neeche di gayi SQL query "Run" kar dein (table bana degi):
create table store_state (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);

alter table store_state enable row level security;

create policy "allow all access"
on store_state for all
using (true)
with check (true);
  1. Project Settings → API mein jayein, wahan se Project URL aur anon public key copy karein.
  2. Upar diye gaye dono boxes mein paste karein aur "Connect Karein" dabayein.

⚠️ Note: ye simple setup bina password/login ke hai — jo bhi is URL aur key ko jaanta hai woh data dekh/badal sakta hai. Chote se dukan ke andaruni istemal ke liye theek hai, lekin key kisi ke saath share na karein.
